# 🍽️ Zomato – Food Delivery Website

A simple frontend website inspired by Zomato, designed to provide users with an easy way to discover restaurants, explore food options, and search for their favourite dishes.

## 📌 Project Overview

This project is a basic clone of the Zomato landing page, developed using HTML and CSS. It features a clean layout with a navigation bar, hero section, restaurant search bar, and food delivery features.

The main objective of this project is to practice frontend web development and understand the structure of a real-world food delivery website.

## ✨ Features

- **Navigation Bar:** Includes Investor Relations, Add Restaurant, Login, and Signup options.
- **Hero Section:** Displays the Zomato branding with a background image.
- **Search Bar:** Allows users to search for restaurants, cuisines, or dishes.
- **Why Choose Us:** Highlights the major benefits of the food delivery platform.
- **Footer:** Displays copyright information.

## 🛠️ Technologies Used

- **HTML5** – For structuring the webpage.
- **CSS3** – For styling and designing the website.
- **JavaScript** – For adding interactive functionality (if implemented).

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/krishan0409-star/Zomato-Clone
   ```

2. Navigate to the project folder:

   ```bash
   cd Zomato-Clone
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code.
